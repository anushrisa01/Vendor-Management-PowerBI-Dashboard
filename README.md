# Vendor Management & Performance Dashboard

## 📌 Project Overview

This project is a two-page interactive Power BI dashboard developed to analyze vendor performance, procurement spending, invoice payment status, invoice aging, and vendor risk.

The dashboard helps procurement and finance teams monitor vendor performance and make data-driven decisions.



## 🚀 Dashboard Features

### Page 1 – Vendor Management Dashboard

- Executive KPI Dashboard
- Procurement Spend Analysis
- Regional Procurement Spend
- Monthly Procurement Trend
- Invoice Payment Status
- Top 10 Vendors by Spend
- Category-wise Spend Analysis
- Interactive Slicers

### Page 2 – Vendor Performance Analysis

- Vendor Outstanding Invoice Details
- Invoice Aging Analysis
- Pending Amount by Vendor
- Top Vendor Rating Analysis
- Vendor Risk Summary
- Average Days to Pay
- Average Vendor Rating
